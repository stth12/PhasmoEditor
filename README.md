# PhasmoEditor 3.0

Редактор сохранений Phasmophobia для Windows x64. Интерфейс: русский.

## Статус совместимости

Это версия для проверки перед релизом. Сохранён алгоритм прежнего редактора:
AES-CBC, первые 16 байт — IV, PBKDF2-SHA1 с 100 итерациями,
JSON с полями PlayersMoney, NewLevel и Prestige, содержащими числовое value.
Алгоритм определён форматом игры; его параметры не заменяются произвольно.

Совместимость с текущей версией Phasmophobia **не подтверждена**:
для проверки требуется свежий файл из игры. Неподдерживаемый формат
блокирует редактирование. Проверки используют искусственные файлы старого формата.

## Установка и использование

1. Распакуйте переносимую сборку Windows x64 и запустите PhasmoEditor.exe.
   Она включает .NET: отдельная установка среды выполнения не нужна.
2. Закройте Phasmophobia и проверьте настройки Steam Cloud.
3. Нажмите «Найти сохранения»: поиск включает вложенные папки
   в %USERPROFILE%/AppData/LocalLow/Kinetic Games/Phasmophobia.
   Либо используйте «Выбрать файл».
4. Проверьте путь и загруженные значения. Измените нужные поля.
5. Нажмите «Проверить и сохранить» и проверьте список изменений.
6. Для отмены выберите копию в разделе «Резервные копии» и восстановите её.

Копии находятся в PhasmoEditorBackups рядом с выбранным файлом.
Каждая запись и восстановление создают отдельную копию.
Копии автоматически не удаляются. Если выбранный файл повреждён,
доступные копии можно восстановить даже после ошибки чтения.
Старые копии SaveFileBackup.txt также отображаются в списке.

Проверяется целочисленный диапазон 0–2147483647; допустимость конкретных
значений для игры требует отдельной проверки. Программа не проверяет
все взаимосвязи игрового прогресса и не управляет Steam Cloud.
Проверка запущенной игры выполняется по имени процесса Phasmophobia.

## Сборка

Нужны Windows и .NET SDK 10.

~~~powershell
dotnet build PhasmoEditorWinApp/PhasmoEditorWinApp.csproj -c Release
dotnet run --project PhasmoEditor.Tests -c Release
dotnet publish PhasmoEditorWinApp/PhasmoEditorWinApp.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/PhasmoEditor
~~~

GitHub Actions собирает программу, запускает проверки и сохраняет переносимую сборку.
Автоматическая публикация релиза не настроена.

## Надёжность записи

Расшифровка выполняется в памяти. Неизвестные JSON-поля сохраняются по значению.
Перед записью новый файл расшифровывается повторно и сравнивается с ожидаемыми данными.
Оригинал заменяется через File.Replace; прежние байты сохраняются в резервной копии.
Если файл изменился после загрузки, запись отклоняется.
Между проверкой изменения и заменой остаётся короткое окно гонки:
закрывайте игру и не редактируйте файл одновременно другими программами.
