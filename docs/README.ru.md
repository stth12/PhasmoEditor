# PhasmoEditor 3.0.0-preview.1

Редактор сохранений Phasmophobia для Windows x64.

[English](../README.md) · [История изменений](../CHANGELOG.md)

## Статус

Это предварительная версия. Совместимость с текущей версией игры
**не подтверждена**: нужен свежий файл сохранения.
Проверки используют искусственные файлы прежнего формата.
Редактирование неподдерживаемого формата блокируется.

## Возможности

- Новый тёмный интерфейс со скруглёнными панелями.
- EN / RU, английский при первом запуске; выбранный язык сохраняется.
- Поиск сохранений во вложенных папках и выбор файла вручную.
- Загрузка текущих денег, уровня и престижа.
- Проверка изменений перед записью.
- История резервных копий и восстановление, включая SaveFileBackup.txt.
- Проверка результата шифрования и защита от записи поверх изменённого файла.
- Пользовательская иконка только у EXE.
- Ссылка на GitHub автора в боковой панели.

## Установка и использование

После публикации скачайте ZIP для Windows x64 из
[Releases](https://github.com/stth12/PhasmoEditor/releases).
Распакуйте и запустите PhasmoEditor.exe. Отдельная установка .NET не нужна.

1. Закройте игру и проверьте настройки Steam Cloud.
2. Нажмите Find / «Найти» либо Open… / «Открыть…».
3. Выберите нужное сохранение и измените значения.
4. Нажмите Review and save / «Проверить и сохранить», проверьте изменения и подтвердите.
5. Для отмены выберите резервную копию и нажмите Restore backup / «Восстановить копию».

Поиск выполняется в
`%USERPROFILE%\\AppData\\LocalLow\\Kinetic Games\\Phasmophobia` и вложенных папках.

Копии находятся в PhasmoEditorBackups рядом с выбранным файлом.
Каждая запись и восстановление создают отдельную копию.
Копии автоматически не удаляются.
Повреждённое сохранение можно восстановить из исправной копии.

Язык меняется кнопками EN / RU без сброса введённых значений.
Настройка хранится в `%LOCALAPPDATA%\\PhasmoEditor\\settings.json`.

## Сборка

Нужны Windows, PowerShell и .NET SDK 10.

~~~powershell
./scripts/prepare-release.ps1
~~~

Скрипт соберёт решение, выполнит проверки и создаст переносимый ZIP
с контрольной суммой в artifacts/release.
GitHub Actions запускает тот же скрипт; релиз автоматически не публикуется.

## Ограничения

Поддерживается прежний формат: AES-CBC с IV в первых 16 байтах,
PBKDF2-SHA1 с 100 итерациями и JSON с числовыми value
для PlayersMoney, NewLevel и Prestige.
Неизвестные поля сохраняются по значению.

Ввод проверяется в диапазоне 0–2147483647.
Допустимые игровые значения и взаимосвязи прогресса пока не проверены.
Программа не управляет Steam Cloud и проверяет запуск игры по имени процесса Phasmophobia.

Для замены файла используется File.Replace с резервной копией.
Файл, изменившийся после загрузки, нельзя перезаписать.
Между проверкой и заменой остаётся короткое окно гонки:
не редактируйте сохранение одновременно другими программами.
