## Что внутри

- **Одно удобное окно.** Скруглённые панели и тёмная зелёная палитра.
- **EN / RU.** Английский при первом запуске; язык переключается без потери введённых значений.
- **Переносимая сборка Windows x64.** Распакуйте ZIP и запустите программу.
- **Копия при каждой операции.** Запись и восстановление сохраняют предыдущий файл.
- **Проверки перед записью.** Неподдерживаемый или изменившийся после загрузки файл не перезаписывается.
- **Локальная работа с файлами.** Программа редактирует выбранный файл и не управляет Steam Cloud.

## Быстрый старт

**Скачать → Распаковать → Открыть → Проверить → Сохранить**

1. После публикации скачайте **PhasmoEditor-3.0.0-preview.1-win-x64.zip** из
   [предварительного релиза](https://github.com/stth12/PhasmoEditor/releases/tag/v3.0.0-preview.1).
2. Распакуйте ZIP и запустите **PhasmoEditor.exe**. Отдельная установка .NET не нужна.
3. Закройте Phasmophobia и проверьте настройки Steam Cloud.
4. Нажмите **«Найти»** или **«Открыть…»** и выберите сохранение.
5. Измените значения, нажмите **«Проверить и сохранить»** и подтвердите изменения.

### Резервные копии

В разделе **«Архив копий»** выберите нужную копию и нажмите **«Восстановить копию»**.
Текущий файл тоже будет сохранён. Повреждённое сохранение можно восстановить из исправной копии.

| Где | Что хранится |
| :--- | :--- |
| `%USERPROFILE%\AppData\LocalLow\Kinetic Games\Phasmophobia` | Здесь выполняется поиск, включая вложенные папки |
| `PhasmoEditorBackups` рядом с выбранным сохранением | История копий; автоматического удаления нет |
| `%LOCALAPPDATA%\PhasmoEditor\settings.json` | Выбранный язык |

Старые **SaveFileBackup.txt** также отображаются в списке.

## Сборка из исходников

Нужны Windows, PowerShell и **.NET SDK 10**.

~~~powershell
./scripts/prepare-release.ps1
~~~

Скрипт собирает решение, выполняет проверки и создаёт ZIP с контрольной суммой
SHA-256 в `artifacts/release`. GitHub Actions использует тот же скрипт;
релиз автоматически не публикуется.

## Ограничения

Поддерживается прежний формат AES-CBC / PBKDF2-SHA1.
В JSON нужны числовые `value` для `PlayersMoney`, `NewLevel` и `Prestige`.
Неизвестные поля сохраняются по значению.

Ввод ограничен диапазоном **0–2147483647**.
Игровые ограничения и взаимосвязи прогресса требуют отдельной проверки.
Закрывайте игру и не редактируйте файл параллельно другими программами:
между проверкой изменения и заменой остаётся короткое окно гонки.
Запуск игры проверяется по имени процесса `Phasmophobia`.
