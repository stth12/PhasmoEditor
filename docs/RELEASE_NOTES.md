# PhasmoEditor 3.0.0-preview.1

## English

A major preview update with a redesigned interface, EN / RU support and
more reliable save handling.

- English is the default language; switch instantly with EN / RU.
- Find saves in nested profile folders or open a file manually.
- Load current values and review money, level and prestige changes before writing.
- Keep separate backups and restore earlier saves.
- Detect unsupported structures, changed files and a running game.
- Portable Windows x64 package with .NET included.
- Custom executable icon; no logo image inside the interface.
- An author GitHub link in the sidebar.

**Compatibility with the current game version is not yet verified.**
Tests use synthetic fixtures of the previous save format.

Extract the ZIP and run PhasmoEditor.exe. Close the game and check Steam Cloud first.
Backups are kept beside the save in PhasmoEditorBackups.

## Русский

Крупное предварительное обновление: новый дизайн, EN / RU и более надёжная работа с сохранениями.

- Английский по умолчанию; мгновенное переключение EN / RU.
- Поиск сохранений во вложенных папках и ручной выбор файла.
- Загрузка текущих значений и проверка изменений перед записью.
- Отдельные резервные копии и восстановление.
- Проверки формата, изменения файла и запущенной игры.
- Переносимая сборка Windows x64 со встроенным .NET.
- Пользовательская иконка только у EXE.
- Ссылка на GitHub автора в боковой панели.

**Совместимость с текущей версией игры ещё не проверена.**
Использованы искусственные файлы прежнего формата.

Распакуйте ZIP и запустите PhasmoEditor.exe. Сначала закройте игру и проверьте Steam Cloud.
Копии хранятся рядом с сохранением в PhasmoEditorBackups.
