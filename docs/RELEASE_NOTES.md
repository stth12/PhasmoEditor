# PhasmoEditor 3.0.0

A major update with a new design, English / Russian support and backup recovery.

**Tested on Phasmophobia v0.19.1.0.**

## What's new

- Redesigned dark interface.
- Instant EN / RU switching.
- Save discovery in nested profile folders.
- Current money, level and prestige values.
- Review changes before saving.
- Backup history and one-click restore.
- Standalone Windows x64 EXE — .NET included.

<img src="images/interface-en.png" alt="PhasmoEditor interface" width="1120">

## Download and run

Download **PhasmoEditor-3.0.0-win-x64.exe** below and run it.
No installer, archive extraction or separate .NET runtime is needed.

Close Phasmophobia and check Steam Cloud settings before editing.

## Русский

Полностью обновлены дизайн и логика приложения. Добавлены EN / RU,
поиск профилей, просмотр изменений и восстановление из резервных копий.

**Все функции проверены на Phasmophobia v0.19.1.0 и работают исправно.**

Скачайте **PhasmoEditor-3.0.0-win-x64.exe** и запустите.
Распаковывать архив или устанавливать .NET не нужно.
